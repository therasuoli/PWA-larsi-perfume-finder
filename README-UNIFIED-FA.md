# Larsi Perfume Finder · 7.1.1

**یک موتور کشف عطر فارسی با رابط Editorial + Luxury**

این نسخه به‌صورت PWA و Mobile-first ساخته شده است. کاتالوگ محصولات فقط از جدول `perfumes` پروژه Supabase تنظیم‌شده دریافت می‌شود. هیچ API عطر خارجی، جستجوی بیرونی، crawler یا Dataset خودکار خارج از فایل‌های مدیریت‌شده مالک پروژه در مسیر برنامه استفاده نمی‌شود.

## ویژگی‌ها
- جستجوی فوری در نام، نام فارسی، برند، نت‌ها، آکوردها، ویژگی‌ها و توضیحات کوتاه/بلند
- Autocomplete محلی برای عطر، برند و نت؛ تاریخچه جستجوی دستگاه
- فیلتر خانواده رایحه، غلظت، فصل، زمان استفاده، نت، برند و ویژگی
- عطرهای مشابه با الگوریتم محلی، مقایسه ۲ تا ۴ محصول، علاقه‌مندی و کمد شخصی
- پشتیبانی از تصاویر درج‌شده در رکورد دیتابیس
- کش کاتالوگ در IndexedDB (تازه‌سازی تا هر ۶ ساعت) و کش PWA
- انبوردینگ سه‌مرحله‌ای، تم‌ها، تنظیم اندازه نوشته و حالت کاهش حرکت
- پاک‌سازی Cache Storage و IndexedDB از «درباره ما» بدون پاک‌کردن کمد و علاقه‌مندی‌ها
- نصب PWA روی موبایل و دسکتاپ؛ GitHub Pages-friendly؛ اجرای سمت کاربر بدون Node.js

## Supabase

در `js/config.js` آدرس پروژه و کلید `anon/public` و نام جدول تنظیم شده‌اند. کاتالوگ از ستون `payload` جدول `perfumes` خوانده می‌شود. برای استفاده عمومی، جدول باید RLS و سیاست خواندن مناسب داشته باشد؛ کلید Service Role هرگز نباید داخل فایل‌های سمت کاربر قرار بگیرد.

## تصاویر

تصاویر در فیلدهای رکوردهای Supabase قرار بگیرند: `image`, `image_url`, `imageUrl`, `photo`, `primary_image`, `cover` یا آرایه `images`/`gallery`. URL تصویر باید HTTPS و مسیر تصویر یا Storage معتبر باشد. هیچ تصویر یا دیتایی به‌صورت خودکار خزش نمی‌شود.

## وارد کردن بانک مالک پروژه

فایل JSON به شکل آرایه‌ای از رکوردهای عطر در `data/extra/` قرار دهید. حداقل فیلدهای هر رکورد: `id`, `name`, `brand`. جزئیات و فیلدهای پشتیبانی‌شده در `data/extra/README.md` هستند. GitHub Actions فقط با commit فایل JSON یا اجرای دستی فعال می‌شود؛ هیچ schedule خودکار خارجی ندارد. Workflow رکوردها را Upsert می‌کند و رکوردهای قبلی Supabase را حذف نمی‌کند.

## تست‌های سورس

- بررسی Syntax: `node --check js/*.js` (بهتر است هر فایل جداگانه بررسی شود)
- اعتبارسنجی خروجی بانک import: `node scripts/validate-data.mjs`
- ساخت بانک مالک پروژه: `node scripts/build-data.mjs [input.json|input.csv]`
