# Larsi Perfume Finder — Supabase Catalog

اپلیکیشن PWA جستجو و کشف عطر، با نمایش کاتالوگ از Supabase.

## امکانات
- جستجو، دسته‌بندی، برندها، علاقه‌مندی، مقایسه و کمد عطر
- دیتابیس کاتالوگ قطعه‌بندی‌شده و کش آفلاین
- همگام‌سازی کاتالوگ با Supabase (در صورت تنظیم Secrets)
- GitHub Pages؛ برای اجرای PWA در مرورگر نیازی به Node.js نیست

## اتصال Supabase
راهنمای نصب و اتصال دیتابیس: `SUPABASE-SETUP-FA.md` — SQL آماده: `supabase/schema.sql`.
