## قابلیت‌ها

### رابط کاربری
- طراحی RTL با اولویت موبایل، فونت **Vazirmatn**.
- سه تم: **شب تیره** / **روز روشن** / **شن و چرم**.
- اسلایدر اندازه نوشته (۹۰٪ تا ۱۲۰٪) با اعمال زنده روی `--font-scale`.
- انبوردینگ اولیه و پذیرش شرایط استفاده.
- اسکلتون لودینگ، انیمیشن shimmer، و بازگشت به بالا.
- میانبر `⌘K / Ctrl+K` برای فوکوس روی جستجو.

### کشف عطر
- بانک **۱٬۴۷۹ عطر** از **۱۶۰ برند** (دیتاست عمومی Scento).
- جستجوی زنده روی نام، برند، کشور، خانوادهٔ بویایی و نوت‌ها.
- فیلتر: جنسیت، کشور، روز/شب، علاقه‌مندی.
- مرتب‌سازی: پیشنهادی، نام، جدیدترین سال، بالاترین امتیاز.
- **Hash-sync** فیلترها در URL (`#q=oud&g=men&t=night&s=year`) برای اشتراک‌گذاری.
- صفحه‌بندی تدریجی («نمایش عطرهای بیشتر»).

### Scent Matching
- **API همسایه‌های Scento** برای پیشنهاد دقیق‌تر با نمایش «نت‌های مشترک» و «تفاوت رایحه».
- **الگوریتم محلی** به‌عنوان fallback: امتیاز بر اساس نسبت نوت‌های مشترک + تطبیق خانوادهٔ بویایی.

### صفحهٔ جزئیات عطر
- هرم نوت‌ها (آغازین / میانی / پایه)، خانواده، سال، جنسیت، فصل.
- گالری تصاویر (در صورت وجود در `perfume-images.json`).
- امتیاز ۵ ستاره (محلی).
- دکمهٔ «دیدن عطرهای مشابه».

### PWA
- نصب روی موبایل و دسکتاپ.
- Service Worker با استراتژی ترکیبی:
  - **ناوبری (HTML)**: network-first با fallback به کش.
  - **تصاویر**: cache-first با سقف ۳۰۰ (LRU).
  - **CSS/JS هم‌مبدأ**: stale-while-revalidate با سقف ۸۰.
  - **API Scento / فونت‌ها**: network-only.
- آپدیت سریع با `skipWaiting` + `clients.claim` و پیام `SW_ACTIVATED`.

### دسترسی‌پذیری
- `aria-pressed`, `aria-live`, `aria-busy`, `aria-modal`, `aria-label`.
- پشتیبانی کامل کیبورد (`Enter` / `Space` روی کارت‌ها، `Escape` برای بستن مودال، `⌘K` برای جستجو).
- `:focus-visible` روی همهٔ عناصر تعاملی.
- کنتراست مناسب در هر سه تم.
