# Perfume Finder v1.3

وب‌اپلیکیشن فارسی و موبایل‌محور برای جستجو و شناخت عطرها با بانک اطلاعاتی Scento.

## قابلیت‌های نسخه 1.3
- دریافت تازه فایل کامل `perfumes.csv`، `houses.csv` و `materials.csv` از مخزن رسمی Scento در هر بار بازشدن برنامه.
- ذخیره نسخه دریافت‌شده در IndexedDB مرورگر برای جستجو و استفاده آفلاین در بازدیدهای بعدی.
- اگر اینترنت یا منبع داده در دسترس نباشد، آخرین نسخه ذخیره‌شده استفاده می‌شود.
- فهرست همه برندها و خاستگاه‌های موجود در دیتاست، بدون محدودیت به فرانسه و امارات.
- فیلتر خاستگاه کشور، جستجوی محلی سریع و نمایش مرحله‌ای 48 عطر برای سبک ماندن رابط کاربری.
- ترجمه توضیحات توصیفی به فارسی با استفاده از فرهنگ واژگان داخلی و تولید شرح فارسی بر پایه خانواده بویایی و نت‌ها.
- نمایش شماتیک هرم رایحه در سه سطح نت آغازین، میانی و پایانی.
- دسترسی به متن اصلی توضیح منبع در بخش بازشونده برای حفظ شفافیت.
- طراحی بازنگری‌شده و واکنش‌گرا.

## نصب و انتشار
1. تمام فایل‌های این پوشه را در ریشه یک مخزن GitHub قرار بده.
2. از Settings → Pages، شاخه اصلی و پوشه root را برای انتشار انتخاب کن.
3. وب‌اپلیکیشن را با HTTPS باز کن؛ Service Worker و IndexedDB در بستر امن مرورگر فعال می‌شوند.
4. بار اول اتصال اینترنت لازم است تا بانک اطلاعاتی دریافت شود. دفعات بعد نیز در هر بازشدن، تازه‌سازی آنلاین انجام می‌شود و نسخه قبلی تا پایان دریافت حفظ می‌شود.

## نکات دقت داده
- فایل CSV عمومی در زمان تهیه این نسخه شامل 1,479 ردیف عطر و 160 برند است؛ تعداد واقعی پس از هر همگام‌سازی از داده دریافتی خوانده و در رابط نمایش داده می‌شود و ممکن است با به‌روزرسانی منبع تغییر کند.
- دیتاست Scento جنسیت را به‌صورت فیلد مستقل ارائه نمی‌کند؛ بنابراین برنامه جنسیت را حدس نمی‌زند.
- تصویر محصول در این منبع CSV ارائه نشده؛ کارت‌ها از تصویر گرافیکی جایگزین استفاده می‌کنند.
- توضیحات فارسی، ترجمه انسانی رسمی Scento نیست؛ ترجمه/بازنویسی محلی و قاعده‌محور بر اساس داده‌های نت و خانواده بویایی است. متن انگلیسی منبع نیز قابل مشاهده است.
- همه داده‌ها در IndexedDB مرورگر همان دستگاه ذخیره می‌شوند؛ پاک‌کردن داده‌های سایت توسط کاربر، این نسخه آفلاین را حذف می‌کند.
