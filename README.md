# Perfume Finder — v1.1

وب‌اپلیکیشن فارسی، راست‌چین و واکنش‌گرا برای کشف عطرهای فرانسوی و اماراتی، با اتصال مستقیم به Scento Perfume API.

## امکانات

- رابط موبایل‌محور و RTL با انبوردینگ و پذیرش شرایط استفاده
- جستجوی آنلاین عطرها از Scento پس از وارد کردن حداقل دو حرف
- دریافت جزئیات و هرم نت‌های آغازین، میانی و پایانی
- پیشنهاد عطرهای مشابه با نمایش نت‌های مشترک
- صفحه‌بندی نتایج جستجوی Scento
- بانک نمونه داخلی برای نمایش اولیه و fallback هنگام قطعی API
- فیلتر کشور/جنسیت برای داده‌هایی که اطلاعات مربوطه را دارند
- PWA و Service Worker برای کش فایل‌های برنامه
- مستندات فارسی endpointها در `SCENTO_API_FA.md`

## شروع سریع

پروژه را روی GitHub Pages منتشر کنید یا با یک وب‌سرور محلی اجرا کنید. برای Service Worker و نصب PWA، HTTPS یا localhost لازم است.

**اتصال API خودکار است.** در این نسخه نیازی به ساخت API Key، ساخت حساب یا تنظیم آدرس Proxy نیست.

## Scento API

- Base URL: `https://www.scento.com/api/perfume/v1`
- مستندات: https://www.scento.com/developers/perfume-api
- OpenAPI: https://www.scento.com/api/perfume/v1/openapi.json
- روش: GET، پاسخ JSON، بدون API Key

راهنمای فارسی و نمونه کد: `SCENTO_API_FA.md`.

## محدودیت‌های مهم

API اطلاعات عطر و نت‌ها و پیشنهاد مشابه را فراهم می‌کند؛ اما عکس محصول، قیمت، موجودی و جنسیت/کشور سازنده برای همه رکوردها تضمین‌شده نیست. برنامه اطلاعات ناموجود را حدس نمی‌زند. برای نتایج آنلاین اینترنت لازم است؛ بانک نمونه داخلی در صورت شکست درخواست حفظ می‌شود.

پیش از استفاده عمومی یا بازنشر داده‌ها، شرایط استفاده Scento را بررسی کنید: https://www.scento.com/terms-of-service#perfume-api

## ساختار فایل‌ها

- `index.html`: ساختار رابط
- `styles.css`: طراحی واکنش‌گرا
- `app.js`: منطق برنامه و اتصال Scento
- `sw.js`: Service Worker
- `manifest.webmanifest`: مشخصات PWA
- `SCENTO_API_FA.md`: مستندات فارسی API
