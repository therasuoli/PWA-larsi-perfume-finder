# Perfume Finder

وب‌اپلیکیشن فارسی، راست‌چین و واکنش‌گرا برای معرفی عطرهای فرانسوی و اماراتی.

## اجرا
فایل‌ها را روی GitHub Pages منتشر کنید یا با یک وب‌سرور محلی اجرا کنید. برای PWA و Service Worker باید برنامه روی HTTPS یا localhost اجرا شود.

## امکانات
- انبوردینگ متحرک و پذیرش شرایط استفاده
- جستجوی نام، برند، کشور و نت‌ها
- فیلتر فرانسوی/اماراتی و زنانه/مردانه/یونیسکس
- صفحه جزئیات با نت‌های آغازین، میانی و پایانی
- پیشنهاد عطرهای مشابه بر اساس نت‌های مشترک در حالت دمو
- پوسته واکنش‌گرا، درباره ما و اعتبار توسعه‌دهنده
- Service Worker برای کش فایل‌های برنامه و تصاویر بارگذاری‌شده

## نکته مهم درباره Scento
نسخه Scento Perfume Compendium که در ChatGPT در دسترس است، یک اتصال خواندنی برای همین محیط است؛ ابزار آن مستقیماً یک REST endpoint عمومی قابل فراخوانی از GitHub Pages در اختیار این وب‌اپ نمی‌گذارد. بنابراین این پروژه با ۱۲ رکورد نمونه و ساختار آماده اتصال تحویل شده و ادعا نمی‌کند که داده‌های زنده Scento داخل آن فعال است.

برای اتصال واقعی، یک API/Proxy عمومی با قرارداد زیر لازم است:
- `GET /perfumes` → آرایه عطرها یا `{ "data": [...] }`
- هر رکورد: `id,name,brand,country,origin,gender,family,top,heart,base,description,image,year`
- `origin`: مقدار `french` یا `uae`
- `gender`: مقدار `women`، `men` یا `unisex`

پس از آماده‌شدن endpoint، آدرس پایه را در `localStorage` با کلید `pf_api_base` تنظیم کنید. مثال در کنسول مرورگر:
`localStorage.setItem("pf_api_base","https://YOUR-DOMAIN.example/api")`
سپس صفحه را تازه‌سازی کنید. اگر endpoint فعال نباشد، داده‌های نمونه نمایش داده می‌شوند.

## تصاویر
در این نسخه برای رکوردهای نمونه از تصویر بطری گرافیکی داخلی استفاده می‌شود؛ فیلد `image` آماده دریافت URL تصویر محصول است. Service Worker تصاویر خارجی‌ای را که مرورگر با موفقیت بارگذاری کند، برای بازدید بعدی کش می‌کند. برای انتشار عمومی، تصاویر را فقط از منابع مجاز/دارای مجوز استفاده کنید و ترجیحاً روی هاست خودتان نگه دارید.
