# Perfume Finder v1.4

وب‌اپلیکیشن فارسی، واکنش‌گرا و قابل نصب برای کشف عطرها از برندها و خاستگاه‌های سراسر جهان.

## قابلیت‌های نسخه 1.4
- استخراج نشانی تصاویر محصول از صفحات واقعی Scento با اولویت JSON-LD نوع `ProductGroup` و `Product`، سپس `og:image` و در نهایت `img/src/srcSet`.
- تبدیل آدرس‌های `/_next/image?url=...` به URL واقعی تصویر، مطابق نمونه سورس HTML بررسی‌شده.
- نمایش تصویر بطری و گالری تصاویر در کارت و جزئیات عطر؛ کش تصاویر در Service Worker برای بازدیدهای بعدی.
- فایل `data/perfume-images.json` برای نگهداری نگاشت شناسه عطر به تصاویر.
- اسکریپت `scripts/sync_scento_images.py` برای خزش کنترل‌شده صفحات محصولات و استخراج URL تصاویر.
- GitHub Actions برای اجرای دستی و به‌روزرسانی ماهانه فهرست تصاویر؛ اجرای ترتیبی و با مکث بین درخواست‌ها، بررسی robots.txt و توقف در پاسخ‌های 403/429.
- پیشنهاد عطرهای مشابه از endpoint همسایه‌های Scento و در صورت عدم دسترسی، الگوریتم محلی براساس نت‌های مشترک و خانواده بویایی.
- حالت شب و روز با ذخیره انتخاب کاربر در مرورگر.
- فیلتر جداگانه عطرهای مناسب روز و شب بر اساس فیلد زمان استفاده دیتاست.
- علاقه‌مندی‌ها با ذخیره محلی و فیلتر نمایش عطرهای نشان‌شده.
- بانک عطرها، برندها و مواد اولیه Scento؛ ذخیره بانک در IndexedDB و استفاده آفلاین از آخرین نسخه موفق.
- رابط کاربری بازطراحی‌شده 2026، انیمیشن‌های ملایم، کارت‌های مدرن و واکنش‌گرایی موبایل.

## روش تصاویر Scento
مستندات استخراج تصاویر در فایل ارسالی کاربر نشان می‌دهد که صفحه محصول Scento می‌تواند تصویر اصلی را در `og:image` و آرایه کامل‌تری را در JSON-LD قرار دهد. همچنین تصویر بطری ممکن است در `srcSet` تگ `img.perfume-image` با URL رمزگذاری‌شده در پارامتر `url` مربوط به `/_next/image` باشد. اسکریپت این سه مسیر را استخراج و URLهای تکراری را حذف می‌کند.

## اجرای استخراج تصاویر
پیش‌نیاز: Python 3.10 یا جدیدتر؛ کتابخانه‌های استفاده‌شده همگی از کتابخانه استاندارد Python هستند.

```bash
python scripts/sync_scento_images.py --max-pages 5
python scripts/sync_scento_images.py --delay 1.25
```

- دستور اول برای تست پنج صفحه است.
- دستور دوم برای پردازش کل صفحات دیتاست است.
- خروجی در `data/perfume-images.json` ذخیره می‌شود. فایل به‌صورت تدریجی به‌روزرسانی می‌شود تا در صورت توقف، نتایج قبلی حفظ شوند.
- برای استخراج مجدد صفحات قبلی از `--force` استفاده کنید.
- اسکریپت ابتدا `robots.txt` را بررسی می‌کند؛ اگر اجازه خزش مشخص نباشد، خزش را انجام نمی‌دهد. در صورت 403 یا 429 نیز متوقف می‌شود.

## نکته معماری مهم درباره GitHub Pages
مرورگر نمی‌تواند در هر بار بازشدن سایت، HTML تمام صفحات Scento را مستقیماً بخواند؛ این کار به محدودیت CORS و سیاست‌های میزبان وابسته است و برای 1,479 صفحه نیز درخواست‌های سنگین ایجاد می‌کند. بنابراین استخراج HTML در محیط GitHub Actions انجام می‌شود (اجرای دستی یا زمان‌بندی ماهانه). وب‌اپلیکیشن در هر بار بازشدن، فایل کوچک `data/perfume-images.json` را تازه دریافت می‌کند و عکس‌ها را به‌صورت lazy-load نمایش می‌دهد. این روش از خزش انبوه توسط هر بازدیدکننده جلوگیری می‌کند.

## راه‌اندازی GitHub Actions
1. فایل‌ها را در ریشه مخزن GitHub قرار دهید.
2. در Settings → Actions → General، اجازه نوشتن برای workflow را فعال کنید (Workflow permissions: Read and write).
3. از تب Actions، گردش‌کار `Sync Scento perfume images` را با `Run workflow` اجرا کنید.
4. پس از commit شدن `data/perfume-images.json`، GitHub Pages فایل جدید را ارائه می‌کند.
5. برنامه در بازدید بعدی manifest را تازه دریافت می‌کند.

- در بسته اولیه، تصویر استخراج‌شده نمونه برای Club de Nuit Intense Man قرار داده شده است. برای سایر محصولات باید GitHub Action اجرا شود؛ تصاویر ممکن است برای بعضی صفحات وجود نداشته باشند یا خزش طبق robots.txt مجاز نباشد.
